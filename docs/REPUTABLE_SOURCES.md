# Reputable Sources (NC Real Estate)

When we add web or API sources, only these (or similarly vetted) sources may be used. No arbitrary scraping.

## State / regulatory

- **NC Real Estate Commission:** https://www.ncrec.gov/ — licensing, rules, consumer info.
- **NC General Statutes (real estate):** official state legislation.
- **NC .gov:** other state agencies (e.g. revenue, environmental) where they publish property/real-estate-related data.

## County / local (examples)

- **County GIS:** parcel data, ownership, boundaries (many NC counties provide GIS portals).
- **County tax/assessor:** property tax, assessments.
- **Clerk of Court / Register of Deeds:** deeds, liens, foreclosures where available via official sites or approved APIs.

## Listings

- **MLS / aggregators:** only official or vetted APIs (e.g. Realtor.com, Redfin, Zillow) or MLS data feeds where we have a formal agreement. No unvetted scraping of listing sites.

## Zoning / permits

- **City/county planning:** official zoning maps, use codes, permit portals.

*This list will be expanded as we add specific integrations. Each collector will document which of these (or which exact URLs/APIs) it uses.*
